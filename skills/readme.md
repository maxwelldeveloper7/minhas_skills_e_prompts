# Skills

Esta pasta reúne exemplos de skills e instruções de sistema usados para orientar modelos de IA em tarefas específicas.

## Conteúdo atual

- `hgf_skill.md` — skill de exemplo para geração procedural de hardware e renderização em SVG.
  - Foca em interpretação de descrições técnicas.
  - Produz saída em formato SVG estruturado.
  - Define regras de execução, parâmetros de controle e formato esperado da resposta.

## Objetivo

Os arquivos desta pasta servem como referência para criar prompts e skills mais completos, reutilizáveis e adaptáveis a diferentes cenários de uso com IA.

## Estrutura

```text
skills/
├── hgf_skill.md
└── readme.md
```

## Como usar

1. Abra o arquivo desejado em `skills/`.
2. Ajuste o texto conforme o cenário de uso.
3. Integre a skill em ferramentas ou ambientes que suportem instruções de sistema ou prompts especializados.
